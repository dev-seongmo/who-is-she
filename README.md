# WhoIsShe

> Upload. Compare. Confirm.  
> A privacy-first follow list comparison tool.

---

## 💡 About

**WhoIsShe** is a fully static web tool that compares two Instagram follow list snapshots and highlights newly added accounts.

This project does **not** connect to Instagram, does **not** use APIs, and does **not** store any user data.

It simply performs a client-side list comparison directly in your browser.

---

## 🔎 Features

- Compare two follow list snapshots
- Detect newly added accounts
- Highlight differences instantly
- Runs entirely in the browser
- No login required
- No backend
- No tracking

---

## 🚫 What This Project Does NOT Do

- ❌ No Instagram API integration  
- ❌ No login automation  
- ❌ No web scraping  
- ❌ No background monitoring  
- ❌ No server-side data storage  

All data remains on your device.

---

## 🛡 Privacy

WhoIsShe is designed with privacy in mind.

- All processing happens locally using JavaScript.
- No uploaded files are transmitted or stored.
- No analytics or tracking scripts are included.

---

## ⚙️ How It Works

1. Export or copy your Instagram follow list.
2. Save it as a text file (one username per line).
3. Upload the **Before** snapshot.
4. Upload the **After** snapshot.
5. The browser calculates the difference and displays newly added accounts.
